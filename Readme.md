BeautySquad1114
Estudio de belleza y estética — Sección 1114
 
Descripción
BeautySquad1114 es una página web desarrollada para un estudio de belleza y estética, creado por estudiantes de la sección 1114. El proyecto tiene como finalidad presentar de manera atractiva y organizada los diferentes servicios ofrecidos por el estudio y facilitar la gestión de citas de los clientes.

El sitio estará enfocado principalmente en servicios de diseño y pigmentación de cejas, pestañas, pigmentación y procedimientos estéticos de labios, así como en la preparación y mezcla de diferentes pigmentos.

Además, el proyecto incorporará herramientas de marketing digital para promocionar los servicios, mejorar la presencia del estudio en medios digitales y facilitar la comunicación con los clientes.

Objetivo general
Desarrollar una página web para un estudio de belleza y estética que permita mostrar sus servicios, gestionar las citas de los clientes y ofrecer una experiencia sencilla, organizada y fácil de utilizar.

Objetivos específicos
Crear una interfaz atractiva, moderna y fácil de utilizar.
Mostrar información detallada sobre los servicios de belleza y estética.
Permitir a los clientes registrarse e iniciar sesión.
Implementar un sistema para gestionar las citas.
Utilizar una base de datos para almacenar la información del sistema.
Implementar la arquitectura MVC para organizar el proyecto.
Incorporar herramientas de marketing digital para promocionar el estudio.
Facilitar la administración de los servicios y las citas.

Arquitectura MVC
El proyecto utilizará el patrón de arquitectura MVC (Modelo-Vista-Controlador) para mantener el código organizado y facilitar su mantenimiento.

Modelo (Model)
Se encargará de la información y comunicación con la base de datos.

Ejemplos:

Usuarios.
Servicios.
Citas.
Horarios.
Información del estudio.
Vista (View)
Será la parte visual con la que interactuarán los usuarios.

Incluirá:

Página principal.
Catálogo de servicios.
Formularios.
Inicio de sesión.
Registro.
Sistema de citas.
Panel administrativo.
Controlador (Controller)
Será el encargado de conectar las vistas con los modelos y controlar las acciones realizadas por los usuarios.
